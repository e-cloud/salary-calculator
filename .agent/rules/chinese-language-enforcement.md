# Language Rules (语言规范)

1.  **语言协议 (Language Protocol)**:
    - **所有输出** (思考过程、回复、文档/Artifacts) **必须** 使用 **简体中文**。
    - **英语限制**: 英语仅限用于代码实体 (变量名、路径、关键字) 和标准技术术语 (如 Angular, MapStruct)。

2.  **思维链 (Thinking Process)**:
    - 模型的内部推理和思考过程必须使用 **简体中文**。

3.  **文档与清单 (Artifacts)**:
    - `task.md`, `implementation_plan.md` 等所有生成的文档必须使用中文。
    - **严禁** 生成英文的任务清单。

4.  **代码注释 (Comments)**:
    - 代码中的所有注释 (Javadoc, 行内注释) 必须使用 **简体中文**。

5.  **零容忍原则 (Zero Tolerance)**:
    - 即使是初步构思、草稿或中间产物，也**必须**直接使用中文生成。
    - **严禁** 先生成英文再翻译。
    - 实施方案 (Implementation Plan) 的所有描述性文字必须为中文。
